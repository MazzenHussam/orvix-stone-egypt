# `src/components/gallery`

## Purpose

Gallery page UI for ORVIX STONE EGYPT.

## Components

- `GalleryHero` — page title
- `GalleryFilters` — All / Projects / Marble / Granite / Factory / Architecture
- `GalleryMasonry` — Pinterest-style masonry
- `GalleryLightbox` — fullscreen viewer with keyboard + touch
