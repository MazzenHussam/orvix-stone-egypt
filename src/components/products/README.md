# `src/components/products`

## Purpose

Editorial Products experience for ORVIX STONE EGYPT.

## Listing

- `ProductsHero` — centered collection intro
- `ProductFilters` — text links with gold active underline
- `ProductEditorialList` / `ProductEditorialRow` — alternating image/text sections

## Detail

- `ProductDetailsHero` — large photography + CTAs
- `ProductGallery` — product photography
- `ProductSpecs` — specifications table
- `ProductMeta` — applications, finishes, forms
- `ProductRelated` — related products

## Data

`src/data/products.ts` (EN/AR via `useLocale().products`)
