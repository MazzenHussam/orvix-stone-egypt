# `src/components/about`

## Purpose

Reusable About page sections for ORVIX STONE EGYPT.

## Sections

- `AboutHero` — 60vh quarry banner
- `AboutStory` — editorial two-column story
- `AboutMission` — centered mission
- `AboutVision` — dark vision block
- `AboutValues` — four-column values
- `AboutJourney` — production timeline
- `AboutWhyEgypt` — editorial photography + copy
- `AboutCta` — closing marble CTA

## Data

Text from `src/data/about.ts` (EN/AR via `useLocale().about`).

## Images

`src/config/images.ts` → `images.about`
