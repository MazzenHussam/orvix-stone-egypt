# `public/images/logos`

## Purpose

ORVIX STONE EGYPT typography wordmarks (SVG only — no icon mark).

| File | Use |
| --- | --- |
| `orvix-wordmark-dark.svg` | Light backgrounds (navbar, favicon source, OG) |
| `orvix-wordmark-light.svg` | Dark backgrounds (footer, dark bands) |

In the React app, prefer `<Wordmark variant="dark|light" />` so Cormorant Garamond and Inter render from the site font stack.
